# 🎮 Shreenath's Tic Tac Toe Game

This is a fun, interactive web-based **Tic Tac Toe** game where a human player (`X`) takes on a simple AI opponent (`O`). It's a great blend of HTML, CSS, and JavaScript — perfect for showcasing front-end skills and interactive UI.

---

## 🔧 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## ✨ Features

- 🎮 Click-based gameplay for `Player X`
- 🤖 Random-move AI for `Player O`
- ♻️ Restart button to play again
- 💡 Dynamic status messages ("X's Turn", "O Wins!", etc.)
- ✅ Responsive, modern UI using clean CSS
- 📱 Mobile-friendly layout

---

## 🚀 How to Run the Game

1. Clone the repository or download the ZIP
2. Open the `index.html` file in any browser (Chrome, Firefox, Edge)
3. Start playing!
